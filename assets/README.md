# README visuals

These assets were created for Vokabelrunde; none was downloaded from GitSkins or a stock library. The design uses two vocabulary cards to show English-to-German recall, with blue (#234AC8), coral (#F57762) and a pale background (#F4F7FF).

- `vokabelrunde-banner.png`: original geometric and typographic artwork drawn with Pillow. The word pair `tree` / `Baum` comes from the included vocabulary list.
- `terminal-demo.gif`: animation rendered from an actual `python3 project.py challenge --num 2` run through a pseudo-terminal. Answers were automated: the stored translation for the first prompt, then `test` for the second. The animation opens on the completed round, then reveals its text in sequence; the timing is edited, not a real-time screen recording. No application behavior or output was invented.
- `terminal-demo.png`: still of the final animation frame, for viewers who prefer a static version.
- `demo.txt`: unmodified captured terminal text (with CRLF normalized), prefixed by the command. Unlike the rendered images, this includes the program's emoji.

The animation wraps long lines and omits emoji glyphs for font compatibility. Menlo was used locally to rasterize the text; no font files are redistributed. The original visuals listed above contain no AI-generated illustration or third-party image content. They are covered by the repository's MIT license. The externally linked YouTube video is not included in that license.

## Keeping the presentation useful

The README should lead with a project-specific visual, a real demonstration and a runnable quickstart. Keep technical explanations accessible below them, and retain the answer-matching limitations and license notices. A text-only cleanup did not satisfy the requested visual README direction; changes to the presentation should be reviewed as rendered images and Markdown, including a narrow viewport.


## Penguin banner: dark and light

`vokabelrunde-penguin-dark.png` and `vokabelrunde-penguin-light.png` are AI-generated editorial illustrations created with the built-in OpenAI image tool. The user-supplied Pengusto profile banner served as a character identity reference only; its rocky island scenery was not reused. The rounded dark penguin, cream face and belly, dark eyes and orange beak/feet remain consistent with that reference.

The project-specific scene turns the existing tree/Baum vocabulary-card idea into a circular carousel. The light image is a palette and lighting edit of the dark image, preserving the character, layout and words. Blue/coral cards and lavender accents connect both versions. No font files, stock images or third-party product screenshots are redistributed.

The README uses native `picture`/`source` theme selection, with the light image as fallback and an alt description. Both compositions were visually checked at 320 and 390 px; no separate mobile image was necessary. The original geometric banner remains in this directory, and the genuine CLI demo is unchanged. These new graphics are included under the repository's MIT license; the external video's rights remain separate.
